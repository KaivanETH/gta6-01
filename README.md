An original top-down open-world crime game set in a sun-soaked seaside city of its own design: explore the city on foot and by car, jack vehicles, dodge a 5-star wanted level with police that chase and ram you, run a chained mission story, fight with melee and firearms, and manage cash, properties and saves — with traffic and pedestrians on every street, a HUD with a minimap, synthesized sound and effects, all from static files in your browser.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

To play: serve the repository's `game/` with any static HTTP server and open `game/index.html` in desktop Chrome, e.g. `node serve.ts` then http://localhost:8080/game/.
