Bahía Dorada is an original top-down open-world crime game set in a fictional sun-soaked bay city: the towers of Centro Dorado, the hotels and palms of Playa Coral, the pastel streets of Barrio Rosa, the suburbs of Las Lomas and the container yards of Los Muelles. You play Sol Ortega, back in town to take down the harbor boss Cruz Varela. You can walk, carjack anything on the road, outrun a five-star police response (roadblocks, a helicopter), fight with fists, a knife and guns, play through seven story missions, buy properties and save your progress.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

How to play: serve `game/` with a static HTTP server and open `game/index.html` in desktop Chrome, e.g. `node serve.ts` → http://localhost:8080/ (serve.ts serves `game/` at the root; a static server started at the repository root serves it at http://localhost:8080/game/). WASD/arrows to walk and drive, E to enter or steal a car, mouse or Space to attack, Esc for the pause menu.
